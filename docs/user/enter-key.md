# Enter moves between fields

By default, Enter saves. If you would rather use Enter to move from box to box, turn on **Enter moves between fields** in **Preferences** (`Ctrl+,`). It is a personal setting. It is off to begin with.

## Off (the default)

| Where | Enter | Shift+Enter |
| --- | --- | --- |
| A box at the top of a form (date, name, number) | Save & New | Save & New |
| A row in a grid or register | Records the row | Records the row |

## On

| Where | Enter | Shift+Enter |
| --- | --- | --- |
| A box at the top of a form | Next box, like Tab | Previous box, like Shift+Tab |
| A cell in a grid | Next cell | Previous cell |
| The last cell of a grid row | Records the row and starts a new line | Previous cell |

**Ctrl+Enter** is Save & New while this setting is on. It works the same in list forms such as accounts, items and tags.

Tab and Shift+Tab always move between fields, whichever way the setting is. Esc works the same too.

Questions asking for a reason (for example when you void something) still use Enter to confirm.
