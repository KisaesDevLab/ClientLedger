# Document viewer

The viewer shows a document you attached, for example next to a bill in Enter Bill, or in the Receipt inbox. It shows PDF, JPG, PNG and multi-page TIFF files.

## Where the viewer appears

- **Enter Bill.**
- **Write Check**, under Attachments.
- **Card charges.** Attach files on a new charge. Files you add before the first save are attached when you save. If a file is still uploading, Save waits for it to finish.
- **Register.** Select a transaction that has a file, then choose **Show document** in the toolbar. The viewer opens in its own window.
- **The Receipt inbox.**
- **The full-size document tab** (see Open full size below).

## Zoom and pages

Use the buttons on the viewer, or the keys below once the preview has focus (click it first).

- **Zoom menu:** choose **Fit page**, **Fit width** or a percentage.
- **+ and − buttons:** zoom in and out.
- **Rotate left and Rotate right buttons:** turn the page. Rotating only changes how you see it. It isn't saved, and the file itself doesn't change. Rotate has no keyboard shortcut.
- **Moving around:** drag the page to pan.
- **Page thumbnails:** a small strip of pages appears when the document has more than one page and the viewer is wide enough.

| Keys | What it does |
| --- | --- |
| `Ctrl++` | Zoom in |
| `Ctrl+-` | Zoom out |
| `Ctrl+0` | Fit: switches between fitting the page to the width and fitting the whole page in view |
| `Page Down` | Next page |
| `Page Up` | Previous page |

The page counter reads "Page 2 of 5". Point at a button to see its shortcut.

## Pop out and Dock

Choose **Pop out**, or press `Ctrl+Shift+D`, to move the document into its own window. You can drag that window to a second monitor and keep the form beside it.

- There is one viewer window. It follows the form or inbox item you are working on.
- The window's title shows the name of the form.
- Its position, size and zoom are remembered for your Windows, macOS or Linux user account.
- If the monitor it was on is gone, choose **Pop out** or press `Ctrl+Shift+D` and the window comes back beside the main window.
- Closing the window never changes your form. Choose **Dock** to put the document back into the form.

| Keys | What it does |
| --- | --- |
| `Ctrl+Shift+D` | Pop out the document, or dock it again |
| `F6` | Move between the form and the viewer |

Screen readers can't read the pop-out window yet. While the viewer is docked in the form, a screen reader can read it.

## Open full size

Choose **Open full size** to show the document in its own tab, where it is easier to read.

## Save a copy

Choose **Save a copy** to put the file in your Downloads folder, for example to open it in another program.

## When the preview isn't available

- **"Preview isn't available on this computer":** the PDF viewer component couldn't be loaded. Use **Save a copy** and open the PDF in another program. Pictures still preview.
- **"This PDF is protected with a password":** save a copy and open it in a program that asks for the password.
- **"This file can't be previewed":** it may be damaged, or too large to show. Save a copy to check it.
- **"Showing the first N pages":** very long documents show only their first pages. Save a copy to read the rest.
- **"Can't be shown":** some kinds of TIFF file can't be displayed here: TIFF files compressed as JPEG, palette (indexed-color) TIFF files, and BigTIFF files. Choose **Save a copy** to open the file in another program.
- **HEIC pictures** (the format some phones use) aren't shown. Save the picture as a JPG or PDF instead, then attach that.

None of these stop you from attaching the file or saving your bill.
