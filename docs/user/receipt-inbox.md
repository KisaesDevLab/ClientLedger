# Receipt inbox

The receipt inbox collects the photos and PDFs your phone, scanner or email saves into a folder, so you can attach each one to a bill, check or bank transaction. Open it from **Vendors > Receipt Inbox**. The menu shows how many files are waiting.

## Choosing the folder

1. Open **Edit > Preferences** and choose **Receipt inbox**.
2. Tick **Watch a folder for receipts**.
3. Enter the full path in **Folder**. Pick a folder your phone or scanner can save into, such as a synced Receipts folder.

The folder must be on this computer or synced to it. A network folder can't be watched. If the folder is renamed, moved or its drive is unplugged, the inbox tells you so. Reconnect it or choose another folder.

## What you see

The inbox lists PDF, PNG and JPEG files in the folder. Choose **Check now** to look again. Each file shows its state:

- **Ready**: you can attach it.
- **Still arriving**: the file is still being saved. Wait a moment.
- **Too large (over 10 MB)**: attachments are limited to 10 MB. Save a smaller copy.
- **Empty file**: nothing to attach.
- **Stored online only**: your sync app (for example a cloud drive) hasn't downloaded the file to this computer. Open the sync app and keep the file on this computer, then it can be attached.

If the folder holds more files than fit in the list, the inbox says how many more there are. Attach or move some to see them.

## Using a file

Pick a file to preview it. Then choose one of:

- **New bill**: opens Enter Bill with the file attached.
- **Add to a bill...**: attaches it to a bill you already entered.
- **New check**: opens Write Check with the file attached.
- **Add to a check...**: attaches it to a check you already wrote.
- **Add to a bank transaction...**: attaches it to a deposit, payment or other bank or card transaction.

For the "Add to" choices, find the record in the list and choose **Attach**.

## Where files go

Files move out of the inbox only after they are attached to a record that has been saved. They move into a **Filed** folder inside your inbox folder, in a subfolder for the year and month, like `Filed/2026-10/`.

- While a new bill or check is still unsaved, the file stays in the inbox. It moves when you save.
- Nothing is deleted, and nothing is overwritten.
- If a file changes while it's being attached, it isn't moved.
- If ClientLedger can't confirm that a file was attached, the file stays in the inbox. Check the record before trying again.
