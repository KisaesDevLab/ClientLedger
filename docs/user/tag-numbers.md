# Tag numbers

A tag can have a number. This is handy if you already number your projects, classes or locations. Add it in the **Tag number** box when you create or edit a tag under **Lists > Tags**.

- The number is optional.
- It can be up to 20 characters, letters or digits.
- A tag with a number shows as "10 · Lake Area" wherever tags are shown or picked.
- Tags list in number order. Numbers made only of digits sort as numbers, so 900 comes before 1000.

## Clearing a number

Empty the **Tag number** box and save. The tag then shows by name only.

## Duplicates

No two tags can share a number. ClientLedger doesn't count capital letters, so "a1" and "A1" are the same number. Inactive tags count too. If you try one that is taken, the tag isn't saved and you see "Another tag already uses number 10." Pick a different number.

If the number is longer than 20 characters you see "The number is too long. Use 20 characters or fewer."

Tag numbers need a recent version of the books engine. Until then the Tags screen says "Tag numbers arrive with the next engine update."
