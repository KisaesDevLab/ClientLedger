Problems to fix before it runs3 problems

⚠Gross profit uses Expenses, which is below it. A formula can only use rows above it. Move the formula down or pick another row. Go to row
⚠Average job mixes dollars with a count of transactions. A formula can only combine rows that add up the same kind of thing. Go to row
⚠Aging columns can't be shown with months side by side. Turn one of them off in Columns.
In the outline the row gets a warning tint; Run report stays off until these are fixed. The preview keeps the last good result.
